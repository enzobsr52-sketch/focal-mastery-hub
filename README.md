# Brasília Photo Academy

Você é um especialista sênior em:

- UX/UI Design
- CRO (Conversion Rate Optimization)
- Landing Pages de alta conversão
- Meta Ads
- Direct Response Marketing
- Copywriting
- Branding premium
- Web Design
- Performance Web

Sua missão é criar um site PREMIUM, extremamente visual e principalmente orientado a CONVERSÃO para a:

ESCOLA TÉCNICA DE FOTOGRAFIA DE BRASÍLIA

Site atual:
https://escolatecnicadefotografia.com.br/

Instagram:
@escoladefotografia.df

A escola possui décadas de atuação no ensino de fotografia e oferece diferentes formações e cursos relacionados à fotografia.

==================================================
OBJETIVO PRINCIPAL

Este projeto NÃO deve ser tratado como um simples site institucional.

O objetivo principal é:

TRANSFORMAR TRÁFEGO DO META ADS EM LEADS, CONVERSAS NO WHATSAPP E MATRÍCULAS.

Imagine que uma pessoa veja um anúncio da escola no:

- Instagram
- Facebook
- Reels
- Stories

e clique no anúncio sem conhecer previamente a escola.

Quando ela chegar ao site, temos poucos segundos para:

1. prender sua atenção;
2. deixar claro o que a escola oferece;
3. gerar desejo;
4. transmitir autoridade;
5. eliminar objeções;
6. mostrar opções de cursos;
7. conduzir para uma ação.

A página deve ser construída para vender.

Não para simplesmente "ficar bonita".

==================================================
REGRA MAIS IMPORTANTE — IMAGENS FORNECIDAS

O usuário fornecerá imagens reais da escola.

Essas imagens são os PRINCIPAIS ATIVOS VISUAIS do projeto.

Utilize prioritariamente as imagens fornecidas pelo usuário.

NÃO substitua automaticamente essas imagens por imagens genéricas de banco de imagens.

NÃO gere imagens fictícias de alunos, professores ou instalações apresentando-as como se fossem reais.

NÃO invente fotografias da escola.

NÃO invente depoimentos.

NÃO invente alunos.

NÃO invente professores.

NÃO invente números.

NÃO invente resultados.

NÃO invente certificações.

NÃO invente prêmios.

NÃO invente informações acadêmicas.

Se uma informação visual não estiver disponível, deixe uma estrutura elegante preparada para receber o material posteriormente.

As imagens fornecidas devem ser tratadas como material oficial da marca.

Exemplo:

FOTO DE INTERAÇÃO ENTRE ALUNOS
→ usar para transmitir experiência.

COPYWRITING

A copy deve ser humana.

Não utilizar frases genéricas como:

"Somos referência em qualidade."

"Oferecemos ensino de excelência."

"Venha fazer parte."

"Invista no seu futuro."

"Você não precisa nascer sabendo fotografar."

"Você precisa aprender a enxergar."

"Comece do zero ou aprofunde aquilo que você já sabe."

"Escolha o caminho que combina com o seu objetivo."

A copy deve vender a transformação sem fazer promessas irreais.
